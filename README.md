# Employee Performance Dashboard | Microsoft Excel

## 📌 Project Overview

The Employee Performance Dashboard is an interactive data analysis and reporting project developed using Microsoft Excel.

The dashboard provides an overview of employee performance across different departments and regions. It helps analyse productivity, achievement levels, task completion, and quality scores through KPI cards, charts, and interactive filters.

The objective of this project is to make employee performance data easier to understand and help management monitor performance trends and identify areas that may require improvement.

## 🎯 Business Objectives

- Monitor overall employee performance.
- Analyse productivity and achievement across departments.
- Track monthly task completion.
- Evaluate employee quality scores.
- Identify high-performing employees.
- Compare performance across different regions.

## 📈 Dashboard Visualizations

The dashboard includes the following analytical views:

1. **Average Achievement by Department** – Compares employee achievement across Finance, HR, IT, Marketing, Operations, and Sales.
2. **Average Productivity by Department** – Shows the distribution of productivity across departments.
3. **Monthly Average Productivity Trend** – Tracks productivity trends from January to July.
4. **Average Achievement by State** – Provides a geographical view of employee performance.
5. **Tasks Completed by Month** – Compares completed and pending tasks across months.
6. **Top 5 Employees by Achievement** – Highlights employees with high achievement scores.

## 🎛️ Interactive Filters

The dashboard provides interactive slicers for:

- Region
- Performance Category
- Department

These filters allow users to explore employee performance across different business dimensions.
